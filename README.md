## Cara menjalankan

Sajikan folder `app/` dengan static server apa saja, lalu buka `app/index.html` di browser:

```sh
cd app
python3 -m http.server 8000
```

Lalu kunjungi `http://localhost:8000/index.html`.

## Fitur

- Tracker 55 trophy — centang progres per trophy, tersimpan lokal di browser.
- Roadmap platinum — urutan langkah yang disarankan menuju Platinum.
- Missable flags — penanda trophy yang bisa terlewat agar tidak ketinggalan.
- Filter — cari dan saring trophy berdasarkan kategori dan status.
- Spoiler setting — sembunyikan detail spoiler sampai kamu siap membacanya.
- Export/import — simpan dan pulihkan progres tracker sebagai file.
